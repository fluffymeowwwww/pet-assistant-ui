# 汤氏在家做什么 · UI 与产品介绍

家庭宠物日常记录与人工核对工具的前端参考仓库，用于在 Google AI Studio 中生成和调整 UI。当前界面参考基线为 v1.1，后续开展 v1.2 设计。

## 文件用途

| 路径 | 用途 |
| --- | --- |
| `app/` | 现行前端 HTML、CSS、JavaScript，优先参考其信息结构和视觉风格 |
| `demo/` | 较早的独立交互原型，含合成数据、插画和合成媒体，可直接运行体验 |
| `PRODUCT.md` | 产品定位、页面与交互要求、数据含义和能力边界 |
| `docs/design/` | 当前视觉规范与颜色、字号等设计 token |
| `ASSETS.md` | 素材来源说明 |

## 预览

运行独立演示，无需安装依赖：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory demo
```

打开 `http://127.0.0.1:4173`。可在首次设置中载入演示样本。数据只保存在当前浏览器，全部设备、记录、检测和提醒均为模拟。

`app/` 是现行界面源代码，依赖 `/api/` 接口；这个仓库没有后端，直接静态打开时显示连接失败属于预期。其前端接口调用用于理解页面交互，不包含接口实现或凭据。`demo/` 能独立预览，但其较早的暖色视觉不代表当前设计规范。

## 给 AI Studio 的任务说明

请阅读 `PRODUCT.md`、`docs/design/` 和 `app/`，以现行界面为依据生成可独立预览的 UI；使用虚构数据表现正常、空白、未知身份、离线、暂停、加载和保存失败状态。需要交互示例时参考 `demo/`。保持行为真假、猫咪身份和异常关注三个维度独立，不将设备动作误写为猫咪行为。当前阶段仅生成前端，不连接真实设备，不索取或嵌入凭据。

## 上传范围

本仓库从前端文件白名单初始化，只有 UI、必要素材及产品与视觉说明。没有原始项目 Git 历史、后端、采集脚本、测试、OpenSpec、开发记录、环境配置、运行数据库、日志、账号凭据、真实事件、参考照片、家庭视频或截图。插画和演示媒体为生成或合成素材。
