# 参考界面视觉风格提取

参考：用户于2026-10-08提供的健康陪伴应用截图。原图1206×2622，分析只针对手机屏幕内部；截图外部背景、设备外壳、状态栏和图片上方说明不属于应用视觉规范。

色值依据截图区域采样，受到压缩、渲染和抗锯齿影响。字号、边距和圆角以约390px移动端宽度估算，下面的规范值用于复用，不表示获得了原始设计稿参数。具体字体无法仅凭截图确认。

## 1. 视觉定位

轻盈、亲切、可信的陪伴型界面。白色页面、近黑正文、青绿主色；浅薄荷和浅杏色用于内容区分。友好感主要来自圆润控件、柔和插画和自然用语。

视觉重点有明确顺序：页面标题 → 主要内容卡片 → 主操作 → 次要内容。主色集中用于选中项、主操作及重要状态。大面积留白与少量低对比边界让页面容易阅读。

## 2. 配色

| 角色 | 建议色值 | 参考依据与用法 |
| --- | --- | --- |
| 页面背景 | `#FDFDFD` | 实测页面白色区域；保留清爽感 |
| 内容/按钮表面 | `#FFFFFF` | 白色卡片与胶囊按钮 |
| 主色 | `#0A8982` | 实测主要按钮约在`#088A82`至`#0A8B82`之间；用于主操作、选中态 |
| 主色浅底 | `#F1F7F5` | 实测主内容卡片底色；用于总结、重点信息 |
| 次要暖色浅底 | `#FCF6F0` | 实测推荐卡片底色；用于温和提示 |
| 暖色强调 | `#EF9859` | 视觉估算；仅用于少量推荐、提醒或次要行动 |
| 正文 | `#161918` | 深近黑色；标题及重要内容。标题采样含`#0E0E0E` |
| 辅助文字 | `#7B817F` | 视觉估算；说明、日期、标签 |
| 边界 | `#E9EEEB` | 视觉估算；轻描边及分隔 |
| 成功状态 | `#58B77B` | 视觉估算；与主色区分的完成状态 |
| 浅蓝辅助底 | `#F0F6FA` | 视觉估算；少量分类入口 |

推荐比例：白色与浅底色约占80–90%；深色文字与图标承担信息；高饱和主色和橙色集中在少数重点。图中浅绿、蓝、橙入口都保持相近的亮度和饱和度，形成协调的同族色。

## 3. 字体与信息层级

无衬线字体，字形清晰、字重扎实。中文可使用系统苹方/思源黑体，英文使用对应平台系统字体；避免同时混用多个字体家族。

| 层级 | 建议字号 / 行高 | 字重 | 用法 |
| --- | --- | --- | --- |
| 页面标题 | 28px / 34px | 700 | 例如Today；每页一个 |
| 主卡片标题 | 20px / 26px | 650–700 | 允许两行，短句优先 |
| 区块标题 | 16px / 22px | 600–650 | 进度、快捷操作等 |
| 主要正文/按钮 | 14px / 20px | 400 / 600 | 内容、按钮标签 |
| 辅助说明 | 12px / 18px | 400 | 日期、说明、状态 |
| 小标签 | 11px / 16px | 500 | 紧凑的分类或时间标签 |
| 关键数字 | 24–28px / 30px | 650–700 | 在同一组中统一大小 |

字号以复用建议为准。核心是标题、正文、辅助信息至少三级，主要通过字号和颜色体现，避免每个标签都加粗。长说明行高约1.4–1.5倍；数字采用等宽数字以减少刷新时跳动。

## 4. 边距与排列

基础间距采用4px步进：4、8、12、16、20、24、32。

| 位置 | 建议值 |
| --- | --- |
| 页面左右边距 | 16–20px |
| 大区块之间 | 20–24px |
| 相邻卡片之间 | 12–16px |
| 主卡片内边距 | 16–20px |
| 紧凑卡片内边距 | 12px |
| 标题与正文 | 8px |
| 文字与图标 | 6–8px |
| 小标签之间 | 4–8px |
| 主要按钮高度 | 44–48px |
| 图标可点击区域 | 至少40px，常规触控目标44px |

卡片左右边缘、区块标题、按钮沿同一内容轴对齐。同一组指标等分排列，标题长度变化也保持数字对齐。图片与正文并排时，图片约占35–45%，保留清晰阅读区域。

参考图的大型主卡片用于承载重点行动，复用到宠物助手时应按实际内容决定高度，避免为了模仿比例增加空白。

## 5. 形状、边界与层次

- 内容卡片：12–16px圆角，1px浅描边，白底或低饱和浅底。
- 常规按钮与小卡片：10–12px圆角。
- 胶囊按钮和状态徽标：999px圆角，仅用于短标签、选项。
- 头像与日期选中态：圆形。
- 主按钮：实色青绿、白字，边界清晰。
- 次级按钮：白底、轻描边、深色文字；阴影可非常轻。
- 阴影：少量使用`0 2px 8px rgba(22,25,24,0.04)`，保持接近无阴影的视觉。

手机外壳的大圆角及大阴影属于展示容器，不应应用到内容卡片。页面内部的圆角随组件用途变化，但数量应控制在少数档位。

### 分隔线使用规则

优先用留白、对齐和容器分组，每一层只使用一种主要分隔方式。线条必须表示清楚的内容边界或控件范围，不能只为修饰而存在。

| 场景 | 规则 |
| --- | --- |
| 卡片之间、页面区块之间 | 使用间距，不额外画分隔线 |
| 卡片内的数字、说明和详情入口 | 使用排列与间距，不默认画横线/竖线 |
| 顶部导航与内容之间、页脚上方 | 用留白衔接，不使用通栏修饰线 |
| 页面导航 | 文字层级和浅色选中底即可，不叠加外框和实色主按钮样式 |
| 同区域视图切换 | 单层浅底轨道和选中项，不再加外框 |
| 卡片外轮廓、表单输入框 | 必要时保留轻描边，用于界定对象或可输入范围 |
| 无卡片的连续密集列表、表格行 | 允许细分隔线，避免相邻记录混淆 |
| 进度连接线、定位框、键盘焦点轮廓 | 属于功能标识，按其语义保留 |

同一组内容已经用卡片或底色分组时，不再叠加内部修饰线。新增边框或分隔线须先说明它界定了什么对象、解决了什么识别问题。

## 6. 元素与图标

图标以圆头、圆角的细线风格为主，约1.5–2px描边。常规尺寸18–20px，导航24px，说明图标16px；同一用途统一尺寸。选中态使用主色，未选中使用灰色。

图中的情绪选项是圆形小插画，快捷操作是带轻色底的小图标，底部导航是线性图标；不同类型分别有固定用法。功能图标适合复用同一图标库，猫咪头像独立作为插画，不混入emoji充当常规操作图标。

日期条由等宽的七列构成，选中日期实色圆形、白字，其他日期保留安静的中性色。进度条采用细连接线与圆形节点，已完成绿色、未完成浅灰，含勾选图标补充颜色含义。

## 7. 插画与图片

插画采用柔和的扁平/轻纹理风格：薄荷绿、鼠尾草绿、杏橙，圆润轮廓，轻质感，无强烈黑色外轮廓。人物或角色只承担陪伴与情绪氛围，不争夺按钮和标题的注意力。

头像是真实照片或统一的一套插画；同组图片必须保持相同裁切比例、主体大小、背景明度与光照方向。宠物助手可保留已用的猫咪头像，通过统一圆形裁切和尺寸融入界面。

## 8. 交互状态

默认、选中、悬停、键盘聚焦和禁用状态应覆盖所有同类控件。选中态同时改变色彩与字重/图形，图标按钮有可访问名称。说明按钮在标题边显示，点击展开说明；不依赖鼠标悬停。

主色实底按钮使用白字；浅底卡片使用深色正文。灰色辅助文字、橙色和绿色状态在实现时仍需核对实际对比度，截图采样不是可访问性验证。

## 9. 对应宠物助手

| 现有区域 | 可提取的规则 |
| --- | --- |
| 今天总结 | 浅薄荷卡片、短标题、深色正文；日期与标题同排 |
| 全家的吃喝日常 | 白色或极浅底，数字统一，说明使用线性信息图标 |
| 按猫咪看 / 按设备看 | 共用青绿选中态、统一圆角与高度 |
| 猫咪卡片 | 统一头像比例、标题字号、指标位置，保持紧凑 |
| 设备卡片 | 继续三列紧凑排布，主指标优先，详情按需展开 |
| 历史、设置、说明弹窗 | 共用字体层级、描边、圆角和按钮规则 |
| 认猫、核对等主操作 | 集中使用青绿主按钮；提醒才使用暖橙色 |

复用的核心是视觉层级、色彩角色和组件规则。示例中的连续打卡、情绪选择、健康进度和底部导航属于其产品结构，不能仅凭视觉参考直接移植为宠物行为或统计能力。

## 10. 日常记录文案

记录标题以猫咪和日常动作为主语，例如「汤圆吃饭了」「飞饼喝水了」「小猫来过了」。已归属事件使用猫咪名字，尚未归属使用「小猫」，多只或部分未知参与者按实际归属描述。仅检测到出现不改写为吃喝，移动信号活动仍未核实时用「好像有小猫路过了」。疑似和已否定状态保留，不因口语化变成确认事实。

设备动作单独写「食盆添粮了」「饮水机出水了」，不指向猫咪吃饭或喝水。标题口语化，来源、时间与核对状态继续显示，详细原始说明保留在详情中。

## 11. 记录详情层级

标题与时间/位置在前，事实状态和身份状态使用轻量标签。现场画面是详情主体，直接承接标题；媒体读取按钮和原图入口放在画面下方，不用独立说明卡片阻挡画面。核实行为的主、次操作集中成组；身份选择与行为核实独立，猫咪选项使用统一头像。参考照片、原始说明、更正历史、候选关联与分析说明按需展开。用间距与浅底区分功能组，不叠加修饰线。

首页仅在采集暂停或设备不可用时显示紧凑状态入口，完整设备状态在设置中维护。

解释统计口径、记录含义和能力边界的文字，默认放在标题旁的线性信息图标中，点击查看；不在内容列表上方另占一行。需要立即处理的异常状态继续直接展示，避免与解释说明混淆。

日常列表的位置筛选使用一排紧凑文字标签，浅薄荷底只用于选中项，其他项不额外描边；标签较多时横向滚动，不让整页横向溢出。筛选属于列表范围，不能改变上方全家汇总。

待认猫与历史页共用紧凑列表布局：返回箭头、标题、数量和日期同排，日期与概览页使用一致的字号、圆角与边界。待认猫的记录行以画面和认猫入口为主，不重复未知身份提示。页头说明通过信息图标按需查看。
